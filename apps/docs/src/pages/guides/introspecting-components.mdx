# Introspecting components

Point Recontent at your components and it reads them with the TypeScript compiler: props, defaults, subcomponents, and referenced types. You add no annotations and maintain no duplicate metadata. [`recontent inspect`](/cli/inspect), [`docs()`](/plugins/docs), [`designMD()`](/plugins/design-md), [`recontent diff`](/cli/diff), and any [plugin](/plugin-api) depending on `introspection` all consume the result.

## Configure introspection

Add `introspection` to your config file and point `entry` at the barrel file that exports your components:

```ts
export default defineConfig({
  tokens: { ref, system, components },
  introspection: {
    entry: "src/components/index.ts",
    exclude: ["ThemeProvider"],
    importPath: "@acme/ds",
  },
  plugins: [docs({ outDir: "docs" })],
});
```

Verify the introspected components with `recontent inspect`:

```bash
recontent inspect
```

See the [config reference](/config#introspection) for all options (`entry`, `tsconfig`, `exclude`, `importPath`).

## What counts as a component

Recontent treats a PascalCase export as a component when it is callable and returns a React-renderable type, or when it is a class with a `render` method. Because the TypeScript compiler resolves each export, plain functions, `FC`, `memo`, `forwardRef`, `lazy`, and class components all work. Recontent skips hooks, constants, enums, types, and PascalCase helpers such as `FormatDate(date): string`.

Recontent reports subcomponents one level deep with dotted names. Both `Object.assign(Tabs, { Item })` and `Tabs.Item = Item` produce `Tabs.Item`, and `export * as Dialog from "./dialog"` produces `Dialog.Root` and `Dialog.Trigger`.

## Props

Recontent extracts detailed prop information for every component:

- **Own vs. inherited props:** Recontent lists props declared in your project separately from props inherited from libraries (such as `ButtonHTMLAttributes` from `@types/react`).
- **`Pick` and `Omit`:** Keys selected with `Pick<LibraryProps, "open" | "onOpenChange">` become your component's own props with their library types and descriptions. `Omit` keeps all remaining props inherited.
- **Union prop types:** Recontent lists every union member's props and marks a prop required only when every member requires it.
- **JSDoc and defaults:** Descriptions, `@default`, and `@deprecated` come from [JSDoc](/guides/documenting-components). Without `@default`, Recontent reads destructuring defaults from the implementation.
- **Type aliases and generics:** Project type aliases keep their name in `type` (`Width`) and expand in `resolved` (`number | "100%" | "auto"`). Library aliases such as `MouseEventHandler<…>` stay as written, and generic components list their type parameters (`Accordion<Value extends string>`).
- **Transitive types:** Recontent follows project interfaces, type aliases, and enums referenced by props and exposes them via `recontent inspect types`. It excludes types from `node_modules`.

## Warnings

Recontent accepts two weak-evidence exports with a warning naming them: an untyped function returning `any`, and a class with a `render` method that does not extend `React.Component`. Add them to `exclude` if they are not components. Recontent also warns when an entry exports PascalCase values but zero components—usually because `@types/react` cannot resolve from `entry`.

## When it runs

Recontent builds the TypeScript program only when a configured plugin depends on components (such as [`docs()`](/plugins/docs) or [`designMD()`](/plugins/design-md)), or when you run `recontent inspect` or `recontent inspect components`. Token-only builds skip introspection completely, so a broken `introspection` block never blocks them. `recontent build --watch` rebuilds when component files inside the entry's package change, and [caching](/config#cache) keeps repeated runs near instant.

## Components only

Tokens are optional when you configure `introspection`. A project can document its components alone:

```ts
export default defineConfig({
  introspection: { entry: "src/components/index.ts", importPath: "@acme/ds" },
  plugins: [docs({ outDir: "docs" })],
});
```

`defineConfig` throws when you omit both `tokens` and `introspection`.
