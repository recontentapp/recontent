# Troubleshooting

Recontent prints every message below to stderr. Pass `--log-level debug` to include a stack trace with errors. See [Log level](/cli#log-level).

## Config not found

```text
error: Could not find a recontent.config.{ts,mts,js,mjs} file. Searched:
  - /path/to/project
Pass -c/--config to point at one explicitly.
```

Discovery starts in the current directory and stops at the first directory containing `package.json`, so it skips configs in parent folders above a package. Run the command inside the folder holding the config file, or pass `-c <path>`. See [config discovery](/cli#config-discovery).

## Broken alias

```text
error: Broken alias at "system.color.bg": target "ref.color.white" does not exist in the registry.
```

A token references a target not registered in `defineConfig`. Add the target's layer (for example `ref`) to `tokens` in `defineConfig`.

## Bare value instead of a token

```text
warning: Unknown token value at "system.bad". Use tokens.color(...) instead of an anonymous value.
```

Recontent ignores plain strings, numbers, or objects that are not token objects. Wrap the value in the matching `tokens.*` factory. See [Primitives](/config/primitives).

## File path collision

```text
error: File path collision at "o/tokens.css": both plugin "recontent:css" and plugin "acme:x" emitted this file.
```

Two plugins (or two instances of one plugin) emit the same output path. Give one plugin its own `outDir` or `filename`. This commonly happens with `typescript()` and `typescriptNative()`, which both default to `tokens.ts`. See [outDir](/guides/using-plugins#outdir).

## Theme name rejected

```text
error: [recontent:stylex] Theme name "my-dark" cannot be used with the "stylex" output target: theme names must be valid TypeScript identifiers.
```

Each plugin uses theme keys as class names, file names, or export names, so each enforces its own naming rules. Use an identifier such as `dark` or `highContrast` that every plugin accepts. See [Working with themes](/guides/working-with-themes#definetheme).

## Key collision in StyleX

```text
error: [recontent:stylex] generate failed: StyleX key collision: token paths "ref.a.bC" and "ref.aB.c" both flatten to "refABC". Rename one of these tokens to avoid an ambiguous generated key.
```

StyleX variables use flat keys, so two paths flattening to the same camelCase key collide. Rename one of the tokens. See [StyleX](/plugins/stylex#emitted-files).

## `diff` cannot compare against a revision

```text
error: Not a valid git revision: "origin/main".
error: Could not determine whether "origin/main" is an ancestor of HEAD: this looks like a shallow clone missing the required history. …
```

`diff` requires the git history between the target revision and `HEAD`. In CI, pass `fetch-depth: 0` to `actions/checkout`; locally, run `git fetch --unshallow`. See [Catching breaking changes](/guides/diffs#github-actions).

## No plugins configured

```text
warning: No plugins configured in recontent.config.ts; add some from "recontent/plugins" to generate output.
```

Without plugins, `recontent build` validates tokens without emitting files. Add at least one plugin to `plugins`. See [Using plugins](/guides/using-plugins).
