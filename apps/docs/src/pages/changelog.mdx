# Changelog

Release notes are published as
[GitHub releases](https://github.com/recontentapp/recontentapp/releases). Each package is released
with its own tag:

- `recontent-v*` for the [`recontent`](https://www.npmjs.com/package/recontent) CLI and plugins;
- `core-v*` for [`@recontentapp/core`](https://www.npmjs.com/package/@recontentapp/core), the token
  model and plugin types that `recontent` builds on.
