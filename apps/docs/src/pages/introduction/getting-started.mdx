# Getting started

This guide takes a few minutes. You will generate CSS variables from a typed config file and inspect your React components with `recontent inspect`. Install [`recontent`](/introduction/installation) before you begin.

## 1. Scaffold a config

Run [`recontent init`](/cli/init) to create `recontent.config.ts` from a preset:

```bash
recontent init neutral
```

Choose from two built-in presets:

- `neutral`: shadcn/ui's neutral base, with OKLCH colors, radius, shadows, light, and dark themes.
- `material`: the Material 3 baseline, with tonal palettes, color roles, a type scale, elevation, and motion.

If you already have DTCG token files, import them with [`recontent init --dtcg`](/cli/init#importing-dtcg-tokens).

## 2. Add a plugin

The scaffolded config file defines tokens and themes without any outputs. Add a plugin from `recontent/plugins`:

```ts [recontent.config.ts]
import { defineConfig /* ... */ } from "recontent";
import { css } from "recontent/plugins";

// ref, system and dark are defined above

export default defineConfig({
  tokens: { ref, system },
  themes: { dark },
  plugins: [css({ outDir: "src/generated" })],
});
```

## 3. Build

Run `recontent build`:

```bash
recontent build
```

```text
Wrote src/generated/tokens.css
Wrote 1 file
```

## 4. Use the output

Import the generated stylesheet once, then reference the CSS variables:

```css
@import "./generated/tokens.css";

body {
  background: var(--system-color-background);
  color: var(--system-color-foreground);
}
```

Each token becomes a CSS variable named after its path, so `system.color.background` becomes `--system-color-background`. In `neutral`, the `system` layer includes `color`, `radius`, `spacing`, `shadow`, and `typography`. The dark theme emits a `.dark` block that overrides only changed tokens. Add `class="dark"` to `<html>` to switch themes.

## 5. Introspect your components

Point Recontent at the barrel file that exports your React components:

```ts [recontent.config.ts]
export default defineConfig({
  tokens: { ref, system },
  themes: { dark },
  introspection: { entry: "src/components/index.ts", importPath: "@acme/ds" },
  plugins: [css({ outDir: "src/generated" })],
});
```

## 6. Inspect

Query your design system from the CLI:

```bash
recontent inspect                    # counts, themes and component names
recontent inspect components Button  # its exact props, defaults and usage notes
recontent inspect tokens system      # tokens with their values and CSS variables
```

Humans, scripts, and coding agents can run these commands at any time. See [Introspecting components](/guides/introspecting-components) and [Coding with agents](/guides/agents).

## 7. Keep going

- Edit tokens in `recontent.config.ts` and run `recontent build --watch` to rebuild on save.
- Add more outputs: [Tailwind](/plugins/tailwind), [vanilla-extract](/plugins/vanilla-extract), [StyleX](/plugins/stylex), [TypeScript](/plugins/typescript), and [DTCG](/plugins/dtcg).
- Learn token structure in [Defining tokens](/guides/defining-tokens).
- Add usage notes and examples in [Documenting components](/guides/documenting-components).
- Catch breaking token and prop changes in pull requests with [`recontent diff`](/guides/diffs).
