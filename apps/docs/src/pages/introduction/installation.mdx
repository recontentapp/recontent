# Installation

Recontent ships as a single npm package, [`recontent`](https://www.npmjs.com/package/recontent). It
provides the CLI, the `defineConfig` / `tokens` API you import in `recontent.config.ts`, and the
built-in plugins from `recontent/plugins`.

## Install

Add it as a dev dependency of the project that owns the tokens:

:::code-group

```bash [npm]
npm install --save-dev recontent
```

```bash [yarn]
yarn add --dev recontent
```

```bash [pnpm]
pnpm add --save-dev recontent
```

:::

Use a current Node.js LTS. The repository's own CI runs on Node 24.

Run the CLI through your package manager (`npx recontent`, `yarn recontent`, `pnpm recontent`), or
add scripts:

```json [package.json]
{
  "scripts": {
    "tokens": "recontent build",
    "tokens:watch": "recontent build --watch"
  }
}
```

## Monorepos

Install `recontent` in the package that contains `recontent.config.ts`. The config is loaded with
`recontent` resolved from the config's own directory, so each package uses the version it
installed.

To run from the repository root, point at the config with `-c`:

```bash
recontent build -c packages/design-system/recontent.config.ts
```

## Config discovery

Without `-c, --config`, `recontent` looks for the config in the current directory and then in each
parent directory. See [config discovery](/cli#config-discovery) for the rules, and the
[CLI overview](/cli#global-options) for every global option.
