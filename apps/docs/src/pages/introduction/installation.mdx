# Installation

Recontent ships as a single npm package, [`recontent`](https://www.npmjs.com/package/recontent). It provides the CLI, the `defineConfig` and `tokens` API for `recontent.config.ts`, and the built-in plugins in `recontent/plugins`.

## Install

Add `recontent` as a dev dependency in the project that owns your tokens:

:::code-group

```bash [npm]
npm install --save-dev recontent
```

```bash [yarn]
yarn add --dev recontent
```

```bash [pnpm]
pnpm add --save-dev recontent
```

:::

Use a current Node.js LTS release. Recontent's own CI runs on Node 24.

Run the CLI through your package manager (`npx recontent`, `yarn recontent`, `pnpm recontent`), or add npm scripts:

```json [package.json]
{
  "scripts": {
    "tokens": "recontent build",
    "tokens:watch": "recontent build --watch"
  }
}
```

## Monorepos

Install `recontent` in the package that contains `recontent.config.ts`. Recontent resolves `recontent` from the config file's own directory, so each package uses the version it installs.

To run from the repository root, pass the config file path with `-c`:

```bash
recontent build -c packages/design-system/recontent.config.ts
```

## Config discovery

Without `-c, --config`, `recontent` searches the current directory and each parent directory for a config file. See [config discovery](/cli#config-discovery) for the rules, and the [CLI overview](/cli#global-options) for every global option.
