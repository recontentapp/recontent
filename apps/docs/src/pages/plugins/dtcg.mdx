# DTCG

`dtcg()` exports tokens in the [Design Tokens Community Group](https://www.designtokens.org/) JSON format for design tools and external pipelines. Use it to sync tokens to Figma (through Tokens Studio) or feed another build tool.

```ts twoslash
// [!include ~/snippets/dtcg.config.ts]
```

## Options

```ts
dtcg(options: DtcgPluginOptions): RecontentPlugin
```

| Option   | Type     | Default  | Description                                   |
| -------- | -------- | -------- | --------------------------------------------- |
| `outDir` | `string` | required | Output directory relative to the config file. |

Plugin name: `recontent:dtcg`.

## Emitted files

| File                  | Content                                             |
| --------------------- | --------------------------------------------------- |
| `tokens.tokens.json`  | Base tokens as a nested DTCG document.              |
| `<theme>.tokens.json` | One file per theme with all tokens resolved for it. |

Do not name a theme `tokens`, because its output file collides with `tokens.tokens.json`.

## Format

The document nests tokens by path (`system` → `color` → `background`). Each token includes `$type` and `$value`, plus `$description`, `$deprecated`, and `$extensions` when present.

- **Aliases:** Export as DTCG references (`"$value": "{ref.color.white}"`).
- **Colors:** Export as `{ colorSpace, components, alpha, hex }` objects.
- **Dimensions:** Export as `{ value, unit }`. Because DTCG supports only `px` and `rem`, the plugin converts `em` to `rem` with the same numeric value and emits a warning.
- **Font weights:** Export as numbers, converting named weights automatically.
- **Composites:** `shadow`, `border`, `transition`, `gradient`, and `typography` follow DTCG shapes. Single-layer shadows emit objects; multi-layer shadows emit arrays.
- **Scales and groups:** `tokens.group()` and scales keep `$description`, `$deprecated`, and `$extensions` on the group object.
- **Group types:** When two or more tokens in a group share one type, the plugin hoists `$type` onto the group. If every token shares one type, `$type` sits at the document root.
- **Gradients:** Record `kind` and `angle` under `$extensions["com.recontent"]`, merging any custom data from `.extend("com.recontent", { … })`.

```json
{
  "ref": {
    "color": {
      "white": {
        "$value": { "colorSpace": "srgb", "components": [1, 1, 1], "alpha": 1, "hex": "#ffffff" }
      },
      "gray900": {
        "$value": {
          "colorSpace": "srgb",
          "components": [0.094, 0.094, 0.106],
          "alpha": 1,
          "hex": "#18181b"
        }
      }
    }
  },
  "system": {
    "color": {
      "background": {
        "$value": "{ref.color.white}",
        "$description": "Page background"
      }
    }
  },
  "$type": "color"
}
```

To go in the reverse direction, run [`recontent init --dtcg`](/cli/init#importing-dtcg-tokens) to generate a config file from existing DTCG files.
