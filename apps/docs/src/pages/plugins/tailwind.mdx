# Tailwind

`tailwind()` emits one CSS file for Tailwind CSS **v4**: your token CSS variables plus a `@theme inline` block mapping them to Tailwind namespaces. Utilities such as `bg-accent`, `p-4`, and `font-sans` resolve to your tokens, and themes switch at runtime through CSS variables.

```ts twoslash
// [!include ~/snippets/tailwind.config.ts]
```

## Setup

Install Tailwind CSS v4, then import the generated file after Tailwind:

```css [src/index.css]
@import "tailwindcss";
@import "./generated/tailwind.css";
```

See the [Tailwind playground](https://github.com/recontentapp/recontent/tree/master/apps/tailwind-playground) for a complete Vite example.

## Usage

Utilities resolve to your tokens (`bg-accent`, `p-4`, `font-sans`) based on the [namespaces](#namespaces) you expose.

### Theme variants

With `themeVariants` enabled, each theme context gets a variant so `dark:bg-surface` applies whenever the theme class or attribute is active:

```css
@custom-variant dark (&:where(.dark, .dark *));
```

When multiple axes are configured, variants include the axis prefix (`mode-dark`, `density-compact`) so you can stack them natively (`mode-dark:density-compact:p-2`).

## Options

```ts
tailwind(options: TailwindPluginOptions): RecontentPlugin
```

| Option                | Type                              | Default          | Description                                                                                                 |
| --------------------- | --------------------------------- | ---------------- | ----------------------------------------------------------------------------------------------------------- |
| `outDir`              | `string`                          | required         | Output directory relative to the config file.                                                               |
| `filename`            | `string`                          | `"tailwind.css"` | Name of the generated file.                                                                                 |
| `theme`               | `object`                          | none             | Maps Tailwind namespaces to tokens. See [Namespaces](#namespaces).                                          |
| `themeVariants`       | `boolean \| string[]`             | `true`           | Emits `@custom-variant` per theme: `true` for all, a list of names, or `false`.                             |
| `resetDefaults`       | `boolean \| "all" \| Namespace[]` | `false`          | Resets Tailwind defaults: `true` for namespaces in `theme`, an explicit list, or `"all"` (`--*: initial;`). |
| `typographyUtilities` | `boolean`                         | `false`          | Emits a `text-<key>` utility that also sets `font-family` for each typography token.                        |
| `layer`               | `string \| false`                 | `"theme"`        | Wraps CSS variables in `@layer <name>`, or disables layering with `false`.                                  |
| `prefix`              | `string`                          | none             | Same as the [CSS plugin](/plugins/css#options).                                                             |
| `themeSelector`       | `"class" \| "attribute"`          | `"class"`        | Same as the [CSS plugin](/plugins/css#options).                                                             |
| `themeAttribute`      | `string`                          | `"data-theme"`   | Same as the [CSS plugin](/plugins/css#options).                                                             |

Plugin name: `recontent:tailwind`.

## Namespaces

`theme` maps Tailwind namespaces to tokens. Each value accepts a token, a scale, or a nested object. **The object structure sets the Tailwind key**: `color: { accent: system.color.accent }` creates `--color-accent` (`bg-accent`, `text-accent`), and a scale appends its step (`primary` with step `500` creates `--color-primary-500`). Pass only stamped tokens from `defineReferenceTokens`, `defineSystemTokens`, or `defineComponentTokens`. Each namespace accepts specific token types:

| `theme` key   | Tailwind variable          | Accepts                                                                                                                           |
| ------------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `color`       | `--color-*`                | color                                                                                                                             |
| `spacing`     | `--spacing`, `--spacing-*` | dimension (a bare token sets the `--spacing` base unit)                                                                           |
| `radius`      | `--radius-*`               | dimension                                                                                                                         |
| `font`        | `--font-*`                 | fontFamily                                                                                                                        |
| `fontWeight`  | `--font-weight-*`          | fontWeight                                                                                                                        |
| `text`        | `--text-*`                 | dimension, or a typography token (also sets `--text-<key>--line-height`, `--letter-spacing`, `--font-weight`, and `--font-<key>`) |
| `tracking`    | `--tracking-*`             | dimension                                                                                                                         |
| `leading`     | `--leading-*`              | number, dimension                                                                                                                 |
| `ease`        | `--ease-*`                 | cubicBezier                                                                                                                       |
| `breakpoint`  | `--breakpoint-*`           | dimension                                                                                                                         |
| `container`   | `--container-*`            | dimension                                                                                                                         |
| `blur`        | `--blur-*`                 | dimension                                                                                                                         |
| `perspective` | `--perspective-*`          | dimension                                                                                                                         |
| `aspect`      | `--aspect-*`               | number                                                                                                                            |
| `shadow`      | `--shadow-*`               | shadow                                                                                                                            |
| `insetShadow` | `--inset-shadow-*`         | shadow                                                                                                                            |
| `dropShadow`  | `--drop-shadow-*`          | shadow                                                                                                                            |
| `textShadow`  | `--text-shadow-*`          | shadow                                                                                                                            |
| `duration`    | `--transition-duration-*`  | duration                                                                                                                          |
| `defaults`    | `--default-*`              | `font`, `monoFont`, `transitionDuration`, `transitionTimingFunction`: one token each                                              |

Except for shadows, each mapped variable points at the token's CSS variable (`--color-accent: var(--system-color-accent)`) so themes switch dynamically. When no theme overrides a shadow, the plugin inlines its literal value so Tailwind opacity and color modifiers work (`shadow-card/50`).

## Emitted files

| File                           | Content                                                                                                                                                                                   |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tailwind.css` (or `filename`) | In order: `@custom-variant` rules, `@theme` resets (with `resetDefaults`), token CSS variables and theme blocks (inside `@layer theme`), `@theme inline { … }`, and any `@utility` rules. |

## Diagnostics

Errors fail the build; Recontent prints warnings to stderr.

| Severity | When                                                                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| error    | A token's type does not match its namespace, or a bare token appears outside `spacing`.                                                                                  |
| error    | Two tokens map to the same variable, `text-<key>` clashes with `--color-<key>`, or an option (`layer`, `prefix`, `themeAttribute`, `theme`, `resetDefaults`) is invalid. |
| warning  | You set `themeAttribute` without `themeSelector: "attribute"` (the plugin ignores it).                                                                                   |
| warning  | A `spacing` key collides with a container size (`sm`, `md`, `lg`…), changing `max-w-*`, `w-*`, and `min-w-*`.                                                            |
| warning  | A theme overrides a shadow, keeping it as a `var()` so opacity modifiers cannot apply.                                                                                   |
| warning  | A theme name matches a built-in Tailwind variant (`sm`, `first`, `hover`…).                                                                                              |
