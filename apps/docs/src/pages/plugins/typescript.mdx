# TypeScript

Two plugins generate a `tokens.ts` module of typed constants for code needing runtime token values: charts, canvas drawing, email templates, tests, or React Native.

| Plugin               | Output format                           | Use it for            |
| -------------------- | --------------------------------------- | --------------------- |
| `typescript()`       | CSS strings (`"16px"`, `"#2563eb"`)     | Web code, charts, SSR |
| `typescriptNative()` | React Native numbers and strings (`16`) | React Native, Expo    |

Both plugins default to `tokens.ts`, so give each its own `outDir` or `filename` when using both together.

## typescript()

```ts twoslash
// [!include ~/snippets/typescript.config.ts]
```

```ts
typescript(options: TypeScriptPluginOptions): RecontentPlugin
```

| Option     | Type     | Default     | Description                                   |
| ---------- | -------- | ----------- | --------------------------------------------- |
| `outDir`   | `string` | required    | Output directory relative to the config file. |
| `filename` | `string` | `tokens.ts` | Name of the generated file.                   |

Plugin name: `recontent:typescript`. Emits `tokens.ts`.

### Generated module

```ts
export const theme = { ref: themeRef, system: themeSystem, components: themeComponents };
export const dark = { ref: darkRef, system: darkSystem, components: darkComponents };

export type RefSpacing = "sm" | "md";
export const refSpacing = theme.ref.spacing;

export const themes = { theme, dark } as const;
export type ThemeName = keyof typeof themes;
export type Theme = (typeof themes)[ThemeName];
export type BaseTheme = typeof theme;
```

- `theme` holds base tokens nested by layer and path. Aliases reference their target token directly so the file mirrors your config.
- Each configured theme exports a matching constant (`dark`) with its overrides applied.
- Each [scale](/config/scales) exports a key union and constant (`RefSpacing`, `refSpacing`) named after its layer and path.
- Every export uses `as const`, giving `theme.system.color.text` a literal type.
- Composites: `shadow`, `border`, and `gradient` emit CSS strings; `typography` and `transition` emit objects keyed by CSS property (`fontSize`, `transitionDuration`…).

## typescriptNative()

```ts twoslash
// [!include ~/snippets/typescript-native.config.ts]
```

```ts
typescriptNative(options: TypeScriptNativePluginOptions): RecontentPlugin
```

| Option         | Type     | Default     | Description                                                         |
| -------------- | -------- | ----------- | ------------------------------------------------------------------- |
| `outDir`       | `string` | required    | Output directory relative to the config file.                       |
| `filename`     | `string` | `tokens.ts` | Name of the generated file.                                         |
| `rootFontSize` | `number` | `16`        | Pixels per `rem` and `em`, since native has no cascading font size. |

Plugin name: `recontent:typescript-native`. Emits `tokens.ts` with the same exports above, formatted for React Native:

| Token type    | Output                                                                                                                   |
| ------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `dimension`   | Pixel number (`1rem` becomes `16`).                                                                                      |
| `duration`    | Millisecond number.                                                                                                      |
| `number`      | Plain number.                                                                                                            |
| `cubicBezier` | 4-number tuple (`[x1, y1, x2, y2]`).                                                                                     |
| `fontFamily`  | First family in the list.                                                                                                |
| `fontWeight`  | Numeric string (`"400"`).                                                                                                |
| `strokeStyle` | `"solid"`, `"dashed"`, or `"dotted"` (unsupported styles fall back with a warning).                                      |
| `color`       | Hex string (`#rrggbb` or `#rrggbbaa`; non-sRGB colors fall back to their closest sRGB hex with a warning).               |
| `border`      | `{ borderColor, borderWidth, borderStyle }`.                                                                             |
| `shadow`      | `{ shadowColor, shadowOffset, shadowRadius, shadowOpacity }`.                                                            |
| `typography`  | `{ fontFamily, fontSize, fontWeight, letterSpacing, lineHeight }`, with `lineHeight` in pixels (multiplier × font size). |
| `transition`  | `{ duration, delay, timingFunction }`.                                                                                   |
| `gradient`    | `{ kind, angle, stops }`.                                                                                                |

React Native lacks equivalents for some CSS features, so the plugin picks the closest supported value and prints a warning:

- Keeps only the first layer of a multi-layer shadow and drops `inset` and `spread`.
- Converts custom `strokeStyle` dashes to `dashed`.
- Converts `double`, `groove`, `ridge`, `outset`, and `inset` strokes to `solid`.

## Diagnostics

These rules apply to both plugins unless noted. Errors fail the build; Recontent prints warnings to stderr.

| Severity | When                                                                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| error    | A theme name is not a valid TypeScript identifier, or collides with a generated export (`theme`, `themes`, `Theme`, `ThemeName`, `BaseTheme`…), a reserved word, or another theme's exports. |
| error    | Two scales produce the same exported name (`RefSpacing`). Rename one of them.                                                                                                                |
| error    | `typescriptNative()`: `rootFontSize` is not a positive finite number.                                                                                                                        |
| warning  | `typescriptNative()`: a non-sRGB color falls back to its closest sRGB approximation.                                                                                                         |
| warning  | `typescriptNative()`: a shadow has multiple layers, `inset`, or a non-zero `spread`.                                                                                                         |
| warning  | `typescriptNative()`: a gradient uses `conic`, or a radial gradient specifies `angle`.                                                                                                       |
