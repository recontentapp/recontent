# CSS

`css()` emits every token as a CSS variable with one selector block per theme. It requires no runtime and works with any framework or plain CSS.

```ts twoslash
// [!include ~/snippets/basic.config.ts]
```

## Usage

With the default `themeSelector: "class"`, add the theme name to the root element's `class` attribute:

```html
<html class="dark"></html>
```

With `themeSelector: "attribute"`, set the attribute instead:

```html
<html data-theme="dark"></html>
```

## Options

```ts
css(options: CssPluginOptions): RecontentPlugin
```

| Option           | Type                     | Default        | Description                                                                                                                     |
| ---------------- | ------------------------ | -------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `outDir`         | `string`                 | required       | Output directory relative to the config file.                                                                                   |
| `filename`       | `string`                 | `"tokens.css"` | Name of the generated file.                                                                                                     |
| `prefix`         | `string`                 | none           | Prefix for CSS variable names (`--<prefix>-ref-color-blue`). Must match `/^[A-Za-z][A-Za-z0-9_-]*$/`.                           |
| `themeSelector`  | `"class" \| "attribute"` | `"class"`      | Selects single-axis blocks with `.dark` / `[data-theme="dark"]`, or multi-axis blocks with `.mode-dark` / `[data-mode="dark"]`. |
| `themeAttribute` | `string`                 | `"data-theme"` | Single-axis attribute name when `themeSelector` equals `"attribute"`. Must match `/^[A-Za-z][\w-]*$/`.                          |

Plugin name: `recontent:css`.

## Emitted files

| File                         | Content                                      |
| ---------------------------- | -------------------------------------------- |
| `tokens.css` (or `filename`) | All CSS variables, then one block per theme. |

## Output details

`tokens.css` emits blocks in this order:

1. One `:root` block for `ref`, one for `system`, and one for `components`, skipping empty layers.
2. One block per theme containing only the CSS variables that theme overrides.

```css
:root {
  --ref-color-gray-50: #fafafa;
  --ref-color-gray-900: #18181b;
}

:root {
  --system-color-background: var(--ref-color-gray-50);
  --system-color-text: var(--ref-color-gray-900);
}

.dark {
  --system-color-background: var(--ref-color-gray-900);
  --system-color-text: var(--ref-color-gray-50);
}
```

- **Names:** `--` followed by the token path joined with `-`. Component tokens omit a layer prefix (`--button-background`).
- **Aliases:** Emitted as `var()` references so theme overrides on referenced tokens flow through automatically.
- **Descriptions:** `.describe()` text appears as a CSS comment above the CSS variable.
- **Composites:** `shadow`, `border`, and `gradient` emit one CSS variable; `typography` and `transition` expand into one CSS variable per member (`--system-typography-body-font-size`). See [Composites](/config/composites).
- **Theme blocks:** Emitted last so they override `:root` at equal specificity.

## Diagnostics

Errors fail the build; Recontent prints warnings to stderr.

| Severity | When                                                                                                    |
| -------- | ------------------------------------------------------------------------------------------------------- |
| error    | `prefix` fails `/^[A-Za-z][A-Za-z0-9_-]*$/`.                                                            |
| error    | `themeAttribute` fails `/^[A-Za-z][\w-]*$/`.                                                            |
| error    | Two multi-axis contexts produce the same CSS selector (for example `.a-b-c`).                           |
| warning  | You set `themeAttribute` without `themeSelector: "attribute"`, or when multiple axes use `data-<axis>`. |
