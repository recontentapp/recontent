# StyleX

`stylex()` generates [StyleX](https://stylexjs.com/) variables (`stylex.defineVars`), one StyleX
theme per Recontent theme and typed key helpers for your scales.

```ts twoslash
// [!include ~/snippets/stylex.config.ts]
```

## Setup

Install `@stylexjs/stylex` and the StyleX plugin for your bundler. The
[StyleX playground](https://github.com/recontentapp/recontent/tree/master/apps/stylex-playground)
shows a working Vite setup.

## Usage

```tsx
import * as stylex from "@stylexjs/stylex";
import { vars } from "./generated/tokens.stylex";
import { darkTheme } from "./generated/themes";
import "./generated/reset.gen.css";

const styles = stylex.create({
  page: { backgroundColor: vars.systemColorBackground, color: vars.systemColorText },
});

export function App({ dark }: { dark: boolean }) {
  return <main {...stylex.props(dark && darkTheme, styles.page)} />;
}
```

## Options

```ts
stylex(options: StylexPluginOptions): RecontentPlugin
```

| Option             | Type                 | Default  | Description                                    |
| ------------------ | -------------------- | -------- | ---------------------------------------------- |
| `outDir`           | `string`             | required | Output directory, relative to the config file. |
| `fontFamily`       | a `fontFamily` token | required | Set on `body` by the generated reset.          |
| `placeholderColor` | a `color` token      | required | Color of input placeholders in the reset.      |

Plugin name: `recontent:stylex`.

## Emitted files

| File               | Content                                                                 |
| ------------------ | ----------------------------------------------------------------------- |
| `tokens.stylex.ts` | `export const vars = stylex.defineVars({ … })`: one flat key per token. |
| `themes.ts`        | `<name>Theme = stylex.createTheme(vars, { … })` for each theme.         |
| `scales.ts`        | A key union and a constant per scale (`RefColorGray`, `refColorGray`).  |
| `reset.gen.css`    | A small CSS reset. Import it once.                                      |

StyleX variables must be flat, so a token's path is turned into a camelCase key:
`system.color.background` becomes `systemColorBackground`, and `ref.spacing.0-5` becomes
`refSpacing05`. Typography and transition tokens get one key per member (`systemTypographyBodyFontSize`).

Aliases are emitted as derived variables, so a theme that overrides a referenced token changes
everything that follows it.

## Diagnostics

Each of these fails the build.

| When                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------------- |
| Two tokens flatten to the same key: `StyleX key collision: token paths "…" and "…" both flatten to "…"`. Rename one of them. |
| A theme name is not a valid TypeScript identifier (`my-dark`).                                                               |
