# vanilla-extract

`vanillaExtract()` generates typed [vanilla-extract](https://vanilla-extract.style/) theme contracts and theme classes from your tokens.

```ts twoslash
// [!include ~/snippets/vanilla-extract.config.ts]
```

## Setup

Add the vanilla-extract plugin for your bundler (for Vite, `@vanilla-extract/vite-plugin`) and install `@vanilla-extract/css`.

## Usage

Apply `themeClass` to a root element and compose `<name>ThemeClass` alongside it on the same element to override tokens additively (or `${brandThemes[brand]} ${modeThemes[mode]}` when multiple axes are configured). Composing on the same element ensures `ref` overrides propagate to aliased `system` and `components` variables. Style descendants with the generated `vars`:

```ts [card.css.ts]
import { style } from "@vanilla-extract/css";
import { vars } from "./generated/tokens.css";

export const card = style({
  background: vars.system.color.background,
  color: vars.system.color.text,
});
```

```tsx [App.tsx]
import { darkThemeClass, themeClass } from "./generated/tokens.css";
import { card } from "./card.css";

export function App({ dark }: { dark: boolean }) {
  return (
    <main className={dark ? `${themeClass} ${darkThemeClass}` : themeClass}>
      <div className={card}>…</div>
    </main>
  );
}
```

## Options

```ts
vanillaExtract(options: VanillaExtractPluginOptions): RecontentPlugin
```

| Option     | Type     | Default           | Description                                   |
| ---------- | -------- | ----------------- | --------------------------------------------- |
| `outDir`   | `string` | required          | Output directory relative to the config file. |
| `filename` | `string` | `"tokens.css.ts"` | Name of the generated file.                   |

Plugin name: `recontent:vanilla-extract`.

## Emitted files

| File            | Content                                                                                                                                                                                                   |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tokens.css.ts` | `vars` (theme contract), `refVars`, `systemVars`, `componentVars`, scale exports, base `themeClass`, and additive `style({ vars })` classes (`<name>ThemeClass` for one axis or `<axis>Themes` per axis). |

## Diagnostics

Each condition below fails the build.

| When                                                                      |
| ------------------------------------------------------------------------- |
| A single-axis theme name or multi-axis name is not a valid TS identifier. |
