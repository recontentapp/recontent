# build

Loads the config, runs every plugin and writes the files they produce.

```bash
recontent build [--watch] [--no-cache]
```

## Options

| Option        | Description                                                                    |
| ------------- | ------------------------------------------------------------------------------ |
| `-w, --watch` | Rerun the build whenever the config file, or a file it imports, changes.       |
| `--no-cache`  | Neither read nor write the [introspection cache](/tokens/configuration#cache). |

Uses the [global options](/cli#global-options) `-c`, `--cwd` and `--log-level`.

## What it does

1. Loads the config and prints a warning for each token tree problem.
2. Checks the aliases. A broken alias (the target does not exist) or a circular one is an error.
3. Runs each plugin's `validate`. If any plugin reports an error, nothing is written.
4. Runs each plugin's `generate` and writes the files, creating directories as needed.

Components are [introspected](/tokens/configuration#introspection) only when a configured plugin
declares `dependsOn: ["components"]`, as `docs()` does. If that fails, the plugins that depend on
components fail with the error attributed to them, and the others still run and write their files.
A plugin that depends on components in a config without `introspection` is a config error.

A file whose content is unchanged is not rewritten (`Skipped … (unchanged)`), and a file a plugin
marks as write-once is never overwritten (`Skipped … (already exists)`). No file outside the
config's directory can be written.

```text
Wrote src/generated/tokens.css
Skipped src/generated/reset.gen.css.ts (unchanged)
Wrote 1 file (1 skipped)
```

With no plugins configured, the build prints a warning and writes nothing.

## Failures

Each problem is printed once, followed by a summary, and the exit code is `1`:

```text
error: [recontent:vanilla-extract] Component "stack" requires config "spacing".
error: build failed: 1 error, 0 warnings
```

Warnings do not fail the build.

## Watch mode

`--watch` builds once, then waits. It watches the directories of the config and of every local file
it imports, and rebuilds shortly after a change (changes are debounced, and a change during a build
queues another one). The set of watched files is refreshed after each build.

A failing rebuild prints its error and keeps watching, so you can fix the config and save again.
Stop with `Ctrl+C`.
