# init

`recontent init` scaffolds `recontent.config.ts` from a preset or DTCG tokens, and configures coding agents (Agent Skill, `AGENTS.md` / `CLAUDE.md`, and MCP configs).

```bash
# Interactive wizard (in a TTY)
recontent init

# Authoring: scaffold config and configure agents
recontent init --preset <neutral|material> [--skill [target]] [--mcp <client>] [--agents-md] [--claude-md]
recontent init --dtcg <path> [--dtcg <path> ...] [--force]

# Existing project or consumer: configure agents only
recontent init --skill
recontent init --from <package|file> --mcp <client> --agents-md

# Non-interactive defaults
recontent init -y
recontent init --from <package|file> -y
```

## Interactive mode

Running `recontent init` with no action flags in an interactive terminal launches a guided wizard:

1. **Project source** — skipped if a `recontent.config.{ts,mts,js,mjs}` file already exists (unless you pass `--force`) or you pass `--from`. Otherwise choose between authoring a design system (from a preset or DTCG tokens) or consuming a published design system (`--from`).
2. **Agent transport** — choose **CLI (`recontent inspect`)** (recommended, no client config needed), **MCP server (`recontent mcp`)**, or **Skip**.
3. **MCP clients** _(when you choose MCP)_ — select from Claude Code (`.mcp.json`), Cursor (`.cursor/mcp.json`), and VS Code (`.vscode/mcp.json`).
4. **Agent guidance** — generate a project-local Agent Skill in `.agents/skills/recontent/SKILL.md` and/or `.claude/skills/recontent/SKILL.md`, plus managed sections in `AGENTS.md` and `CLAUDE.md`, tailored to the chosen transport.

## Presets

| Preset     | Description                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------------- |
| `neutral`  | shadcn/ui "neutral" base color: OKLCH color roles, radius, shadows, light and dark.               |
| `material` | Material 3 baseline (seed `#6750A4`): tonal palettes, color roles, type scale, elevation, motion. |

## Options

| Option                   | Description                                                                                                                                                                                       |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--preset <name>`        | Scaffold `recontent.config.ts` from a built-in preset (`neutral`, `material`). Mutually exclusive with `--dtcg` and `--from`.                                                                     |
| `--dtcg <path>`          | Generate `recontent.config.ts` from DTCG tokens instead of a preset. Pass multiple paths to merge them.                                                                                           |
| `--force`                | Overwrite an existing config file. Without `--force`, `init` exits with code `1`.                                                                                                                 |
| `--from <package\|file>` | Configure agent integrations for a published design system snapshot. Mutually exclusive with `--preset`, `--dtcg`, and `-c`.                                                                      |
| `--skill [target]`       | Write a project-local Agent Skill to `agents` (`.agents/skills/recontent/SKILL.md`), `claude` (`.claude/skills/recontent/SKILL.md`), or `all` (repeatable or comma-separated; default: `agents`). |
| `--mcp <client>`         | Configure MCP server for `claude`, `cursor`, `vscode`, or `all` (repeatable or comma-separated). Switches agent mode to MCP.                                                                      |
| `--agents-md`            | Add or update the managed Recontent section (`<!-- recontent:start -->` ... `<!-- recontent:end -->`) in `AGENTS.md`.                                                                             |
| `--claude-md`            | Add or update the managed Recontent section in `CLAUDE.md`.                                                                                                                                       |
| `--design-md <path>`     | Path to `DESIGN.md` referenced by generated agent files. Auto-detected (`DESIGN.md`, then `docs/DESIGN.md`) when omitted.                                                                         |
| `-y, --yes`              | Skip interactive prompts and accept defaults (`--preset neutral` if no config exists and no `--from`, plus `--skill` when you pass no agent flags).                                               |

`init` writes the config to `-c, --config` when provided, or `recontent.config.ts` in `--cwd`. Unlike other commands, `init` does not run config discovery.

## Agent mode (CLI vs. MCP)

Generated skills and instruction blocks never mix CLI and MCP workflows:

- Passing `--mcp <client>` selects **MCP mode**: `init` writes the client JSON configs and tailors `--skill`, `--agents-md`, and `--claude-md` to the `recontent` MCP tools.
- Omitting `--mcp` selects **CLI mode**: `init` tailors `--skill`, `--agents-md`, and `--claude-md` to `recontent inspect` (appending `--from <package|file>` in consumer mode, or `-c <path>` when you pass a custom config path).

Re-running `recontent init` updates managed blocks in `AGENTS.md` / `CLAUDE.md` in place and merges only the `"recontent"` server entry into existing MCP JSON files without disturbing other servers.

## Importing DTCG tokens

Pass `--dtcg` one or more times with these inputs:

- A **resolver** file (`*.resolver.json`, or any JSON with a resolver `$schema`). Pass it as the sole source.
- One or more **token files** (`*.json`).
- **Directories**, which `init` searches recursively for `*.tokens.json`.

`init` merges multiple token files in the order you pass them. When two files define the same token with different values, the later file wins and `init` prints a warning.

```bash
recontent init --dtcg design/tokens/
recontent init --dtcg design/resolver.json -c packages/tokens/recontent.config.ts
```

How `init` maps DTCG tokens:

- Literal values become `ref` tokens. Aliases (`{color.blue}`) and composites containing aliases become `system` tokens pointing to the final `ref` token.
- Group names, descriptions, and deprecations stay intact.
- When `$type` is missing, `init` infers it from the value where possible and prints a warning.
- In a resolver, each modifier's default context merges into the base tokens. Modifiers preserve their axis names, `default`, `description`, non-default contexts, and `resolutionOrder`, using `defineThemeAxis` when needed. Plain-alias overrides reference their target `ref` token, while other overrides emit literals.

`init` skips unsupported entries and prints a warning for each:

- Unsupported token types (such as `string`).
- Colors outside hex strings and supported [color spaces](/config/primitives#color).
- Dimensions in units other than `px`, `rem`, and `em`.
- Aliases pointing to missing tokens.
- JSON pointers referencing external files.

The final summary line reports how many tokens and themes `init` imported and how many entries it skipped.

Review the generated config file before building; it is plain TypeScript ready for you to edit.
